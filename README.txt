PERSONAL HEALTH TRACKER — LOCAL DATA

The app stores entries in the browser/Web App localStorage on this iPhone only. It does not send records to a server.

To install as an offline-capable Home Screen web app, host the folder on an HTTPS static site, open the URL in Safari, use Share > Add to Home Screen, and launch from the new icon. After the first successful visit the service worker caches the app shell for offline use. The web hosting provider receives ordinary page requests but not your stored health entries.

IMPORTANT: Opening index.html directly from Files or ChatGPT preview is not a reliable way to use the app. Do not switch between preview, Safari and the Home Screen app and expect records to appear in all three. Do not clear Safari website data or delete the Home Screen app without first exporting a JSON backup.

Settings > Export JSON backup: full restore-ready data. Settings > Export CSV: spreadsheet and trend analysis. Export and save to On My iPhone regularly.

Apple Health: CSV exercise import requires a CSV with date,activity,duration,intensity columns. Direct HealthKit sync is NOT implemented and would require a native iOS app.

Reminders: Settings can export a recurring calendar file; reliable push notifications are NOT implemented.
